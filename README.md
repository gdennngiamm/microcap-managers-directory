# Microcap managers directory

Data-only copy of the manager profiles and list used by the Microcap Atlas site (gdennngiamm/microcap-atlas, main at 792b886, copied 2026-10-19).

- data/managers.json: 100 managers (default view: Microcap scope, 26)

- data/atlas/discovery.json: discovery leads, not fully verified

Source of truth for the live site stays in microcap-atlas. This copy does not feed the site and can drift. Public-source data only: no emails, outreach status or private notes.
