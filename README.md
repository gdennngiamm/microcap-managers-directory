# Microcap Managers

Public, source-linked directory of microcap investment managers: table and cards, strategies, reported returns (with period and fee basis) and dated portfolio disclosures. Not a ranking, not investment advice.

- data/managers.json: manager list (the site shows strict Microcap scope only)
- data/enrichment.json: source-checked country and style tags
- data/atlas/discovery.json: discovery leads, shown in the same list tagged "not fully verified" (only those whose source says exactly micro-cap)

Data is a copy from the Microcap Atlas research sheet (gdennngiamm/microcap-atlas, import batch 1, 2026-10-19). Public-source data only.

Run: npm install, npm run dev. Build: npm run build. No environment variables, database or sign-in.
